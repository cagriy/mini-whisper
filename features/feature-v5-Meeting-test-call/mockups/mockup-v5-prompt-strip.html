The other options: Script pane (script-pane), Prompt card (prompt-card). Pause is disabled in a test call; Stop ends it. What differs between the options: where the teleprompter sits and how much of the script it shows. Design language: the accepted v4 Meeting Window (mockup-v4-meeting-window.html) and the v5 TEST tag.
