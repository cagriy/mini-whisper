# Native Swift macOS rewrite — Design v1

**Status:** Draft
**Date:** 2026-09-01
**Storm:** [feature-storm-v1-Native-Swift-macOS-rewrite.md](./feature-storm-v1-Native-Swift-macOS-rewrite.md)

## 1. Summary
Mini Whisper is rebuilt as a native Swift macOS menu-bar app that replaces the Python/PyObjC app (v0.1.8, `../mini-whisper`) in place: same bundle ID `com.ips.mini-whisper`, same `~/.config/mini-whisper/` files, same Keychain items, same Homebrew cask, signed and notarised the same way. The rewrite reproduces every user-visible behaviour of the source, replaces the per-press `AVAudioEngine` start/stop with an idle-stop lifecycle and an event-driven UI path so a warm press shows recording in under ~50 ms, fixes five latent defects, makes invalid Settings states unrepresentable, and adds local history with a vocabulary list and per-app cleanup profiles. It is structured as a testable Swift package (`MiniWhisperCore`) plus a thin AppKit/SwiftUI app target generated by xcodegen, targeting macOS 14 with SpeechAnalyzer available on macOS 26.

## 2. Goals and non-goals
- **Goals:**
  - Drop-in upgrade: existing users keep hotkeys, prompts, engine choice, volume, usage, pricing overrides and all Keychain keys with no manual step; TCC grants carry over (§5.10).
  - Behavioural parity with v0.1.8 for every capability in storm §2, including edge-case guards, HTTP error strings, menu labels, onboarding steps.
  - Warm press→visible-recording < 50 ms; capture live within one 1024-frame buffer (~21 ms at 48 kHz) of the press when the engine is running.
  - Overlay reproduces the source physics numerically and follows the accepted “Breathing” mockup; 60 fps with no per-frame heap allocation.
  - Settings cannot express key-less cloud engines or key-less cleanup; the app is usable with zero API keys via on-device engines.
  - Fixes: clipboard restore, overlay follows the active display, discarded dictations do not bill tokens, single instance, toggle cap.
  - History (0–30 days, default 7), vocabulary list, per-app profiles (cleanup prompt, cleanup on/off, submit key) work end to end.
  - Unit tests for every Core component; CI on `macos-26` builds, signs, notarises, releases and updates the cask.
- **Non-goals:**
  - Changes to the Python repo (read-only reference).
  - Toggle-mode visual indicator, caption feedback for silent key-less fallback (superseded by gating), pricing overrides UI, per-app transcription instructions, built-in profile presets, automatic vocabulary learning, live typing into the target app, Accessibility-API text insertion, Shortcuts/CLI service, auto-update framework — all deferred by the storm.
  - Intel builds (arm64 only, as today).

## 3. Requirements
Functional (F) and non-functional (N). Each is testable.

**Identity and configuration**
- F1. Bundle ID `com.ips.mini-whisper`, `LSUIElement`, app name “Mini Whisper”, `CFBundleShortVersionString` starting at 0.2.0.
- F2. Reads and writes `~/.config/mini-whisper/config.json`, `prompt.txt`, `transcribe_prompt.txt`; creates defaults on first run identical to the Python defaults; backs up corrupt JSON to `config.json.bak`; performs the one-shot `daily_usage`→`usage` migration; preserves unknown keys on save.
- F3. Keychain: service `mini-whisper`, accounts `openai-api-key`, `elevenlabs-api-key`, `speechmatics-api-key`, login keychain generic passwords; keys never written to disk or logs.
- F4. New config keys with defaults: `history_retention_days` 7, `idle_stop_seconds` 60, `toggle_max_seconds` 300, `vocabulary` `[]`, `profiles` `[]`, `speech_model_prompted` false; `streaming_engine` accepts `speech_analyzer`.

**Hotkeys**
- F5. Combo grammar identical to `hotkey.py:72-104`: `+`-separated; modifiers `cmd|shift|ctrl|alt`; triggers `space|tab|enter`, single characters via the fixed vk table, modifier-triggers `cmd_r|shift_r|ctrl_r|alt_r`; exactly one trigger. Display format identical to `format_hotkey` (`⇧Right ⌘`, `⌘⇧Space`).
- F6. Matching: modifier-trigger bindings fire only when the held modifier set equals `binding.modifiers ∪ {canonical(trigger)}`; key-trigger bindings fire when held modifiers ⊇ `binding.modifiers` and the key matches. Release on trigger-up or any binding-modifier-up; a safety-net pass deactivates any binding whose modifiers are no longer held; a 100 ms watchdog polls `CGEventSourceFlagsState` for **all** active bindings (including modifier-trigger ones — the source excluded them, `hotkey.py:286`).
- F7. Capture mode: non-modifier press ends capture with (held modifiers, key); releasing a modifier with no non-modifier pressed yields a modifier-trigger combo; bare non-modifier keys are rejected and capture re-enters; Esc cancels; result applied on the main actor and saved.
- F8. Two bindings: `paste` (config `hotkey`, default `shift+cmd_r`) and `paste_submit` (config `submit_hotkey`, default `cmd_r`).

**Dictation pipeline**
- F9. Press with no active recording → overlay shows immediately in `starting` state; capture begins (engine started if needed); when the first buffer arrives the state becomes `recording` and the “on” sound (`on.mp3`) plays. If capture is not live within 100 ms of the press, the system sound “Tink” plays once at that moment (the tick); the “on” sound still plays when live.
- F10. Release after ≥ 0.3 s held → stop and process (push-to-talk). Release before 0.3 s → toggle armed; the next press stops and processes. A toggle-armed recording stops automatically at `toggle_max_seconds` with the “off” sound.
- F11. Recording gate: duration < 0.5 s or mean per-buffer RMS < 0.005 → discard (stream discarded but streamed seconds billed), “off” sound, overlay hides.
- F12. Processing: streamed transcript used when `ok && !text.isEmpty && !sink.failed`; otherwise batch `gpt-4o-mini-transcribe` (30 s timeout, `instructions` = composed transcription instructions). Empty raw text → “off”, hide, nothing pasted. Cleanup (`gpt-4o-mini`, temperature 0.3, 15 s timeout) runs when effective cleanup is on (F26). Then paste, “off” sound, `result`, usage rows refreshed.
- F13. No OpenAI key: if a usable streamed transcript exists → paste it raw (no cleanup, no batch); else overlay error `No API key configured` and nothing pasted.
- F14. HTTP errors: 401 → `Invalid API key — please update in Settings.`; 429 → `Rate limited — please wait and try again.`; other → `API error (<code>).`; other failures → the error's description. Errors show in the overlay for 3 s with the “off” sound.
- F15. Generation guard: a new press during processing increments the generation; the in-flight job checks staleness before batch transcription, before cleanup and before paste; a stale job stops, records only streamed seconds and their per-minute cost, plays “off”, hides.
- F16. Press while recording (toggle not armed) is ignored. Mic start failure → overlay error `Mic error: <reason>`; no stream started.
- F17. Profile and paste target are resolved at release time from `NSWorkspace.shared.frontmostApplication` (bundle ID, name, pid).

**Audio engine and latency**
- F18. One `AVAudioEngine` with a 1024-frame tap at the hardware input format. The engine starts on first press and stays running; it stops `idle_stop_seconds` after the last dictation ends (any terminus), on system sleep, and on quit. Capture is gated by a flag flip while the engine runs.
- F19. `AVAudioEngineConfigurationChangeNotification` during capture ends the recording with error `Audio device changed`; outside capture it marks the engine stopped so the next press restarts it with the new format.
- N1. Warm press→`recording` state on screen ≤ 50 ms; press→overlay visible ≤ one frame (~17 ms). No polling anywhere on the press path.
- N2. WAV for batch: 16 kHz mono int16, linear-interpolation resample from the hardware rate at stop time (same algorithm as `recorder._resample`). Streaming conversion is the stateful chunked equivalent of `audio_convert.py`.

**Streaming engines**
- F20. Engines: `speech_analyzer` (macOS 26+), `on_device` (SFSpeechRecognizer, on-device, partials), `openai` (Realtime, 24 kHz, server VAD, `gpt-live-transcribe`), `elevenlabs` (`scribe_v2_realtime`, 16 kHz), `speechmatics` (EU RT v2, 16 kHz, binary AddAudio) with the exact message shapes in §5.4. Cloud engines buffer up to 60 s of audio before the socket opens, then fail. Terminal event counts only after end-of-audio is on the wire; OpenAI and ElevenLabs drain 0.2 s after it.
- F21. `finish()` waits at most 5 s; on timeout or failure the stream is unusable and partial text is discarded. Engine failure raises `captionUnavailable` once per dictation.
- F22. Transcript assembly: finals joined by single spaces plus trailing partial; segment-restart heuristic identical to `base.py:_is_segment_restart`.
- F23. Engine selection at press time: streaming disabled → none; `speech_analyzer` on < 26, assets not installed, or locale unsupported → SFSpeechRecognizer (with the same Speech permission flow as `on_device`); `on_device` → SFSpeechRecognizer with Speech permission requested on first use (undetermined → batch this time; denied → batch plus one-per-run overlay pointer `Live transcript off: enable Speech Recognition in System Settings → Privacy & Security.`); cloud engine whose key is missing from the Keychain → on-device default plus one caption line `Live transcript: <Engine> key missing — using on-device` once per run.
- F24. SpeechAnalyzer: `SpeechTranscriber(locale:, transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: [])`; results with `isFinal == false` → partial, `isFinal == true` → final. Assets installed via `AssetInventory` after the user accepts the first-launch dialog (F32) or presses Download in Settings. No Speech Recognition TCC prompt on this path.

**Paste and clipboard**
- F25. Paste: snapshot the general pasteboard (all items and types), write the text, post ⌘V key-down/up via `CGEventPostToPid` to the target pid, and for `paste_submit` post the profile's submit key (Enter, ⇧Enter or ⌘Enter) 150 ms later. 300 ms after the last synthetic event, restore the snapshot if the pasteboard's `changeCount` still equals the value after our write. Before posting, `AXIsProcessTrusted()` false → overlay error `Accessibility permission lost — re-enable in System Settings` and nothing posted.

**Cleanup, profiles, vocabulary**
- F26. Effective cleanup = `cleanup_enabled` ∧ OpenAI key present ∧ resolved profile's `cleanup_enabled`. The Settings toggle is disabled (shown off) without a key; the stored value is preserved.
- F27. Profiles: ordered list of `{id, name, bundle_ids, cleanup_enabled, submit_key, cleanup_prompt}`; a bundle ID belongs to at most one profile (Settings enforces); resolution = first profile containing the frontmost bundle ID, else the implicit Default (top-level `cleanup_enabled`, `prompt.txt`, Enter).
- F28. Vocabulary: non-empty list appends `\n\nVocabulary (spell exactly as written): a, b, c` to the transcription instructions and `\n\nPreserve these terms exactly as written: a, b, c` to the cleanup prompt in use.

**History**
- F29. Every delivered dictation appends `{id, ts, text, app_name, bundle_id, engine, streamed_seconds, cost_usd}` to `~/.config/mini-whisper/history.jsonl`. Entries older than `history_retention_days` are pruned at launch and after each append. Retention 0 deletes the file and disables writes. History window: search (case-insensitive substring), Copy, Paste into <previous app>, Delete, Clear History… (confirm). Opened from the menu item `History…`.
- F30. Paste from History: hide the window, activate the previously frontmost app, paste via F25 to its pid with the Default profile's submit behaviour disabled (no submit key).

**Menu bar, onboarding, sounds, usage**
- F31. Menu order: `Today: …`, `Month: …`, [`Last: "…"` after first success], separator, `History…`, `Settings…`, separator, `About Mini Whisper`, `Quit`. Row formats as `pricing.format_usage_rows`. `Last:` click copies and plays “on”.
- F32. First launch on macOS 26 with `SpeechTranscriber.isAvailable`, assets not installed and `speech_model_prompted` false → after normal start, an alert `Download the on-device speech model?` with Download / Not now; either sets `speech_model_prompted` true. Default engine when `streaming_engine` is absent from config.json: `speech_analyzer` on 26 once installed, else `on_device`; a present value is honoured.
- F33. Onboarding: same steps, labels, deep links, 1.5 s poll and unclosable window as the source; Continue starts normal operation in-process (no relaunch).
- F34. Sounds: `on.mp3`, `off.mp3` bundled; tick = `NSSound(named: "Tink")`; all scaled by `sound_volume`; volume slider previews “on” on release.
- F35. Usage/cost: per-day entries under `usage` as today; month pruning on write; pricing table and `pricing_overrides` as `pricing.py` with one added per-minute rate `speech_analyzer: 0.0`; discarded dictations bill only streamed seconds.
- F36. Single instance: at launch, if another `com.ips.mini-whisper` process is running, activate it and exit.
- F37. Overlay and caption are positioned at each show on the display holding the frontmost app's focused window (AX), falling back to the display under the mouse, then `NSScreen.main`.
- F38. `--debug` writes DEBUG logs to `/tmp/mini-whisper.log` in addition to unified logging; otherwise INFO to unified logging only. No transcript text, keys or prompt contents at INFO.

**Non-functional**
- N3. macOS 14.0 deployment target, arm64, Swift 6 language mode with strict concurrency, no third-party runtime dependencies.
- N4. Hardened runtime, Developer ID signature under Team `XPRCQRLN7Y`, not sandboxed; entitlement `com.apple.security.device.audio-input`.
- N5. Every Core component has unit tests runnable with `swift test` without audio hardware, network or TCC.
- N6. The Python app can still read a config.json written by this app (new keys ignored; `speech_analyzer` engine value falls back to its first popup item and batch).

## 4. Background and context
- Source app modules and behaviours are inventoried in the storm and were re-read for this design: `controller.py:101-127` (press/release, 0.3 s threshold), `controller.py:186-320` (processing pipeline), `recorder.py:60-110` (tap, RMS, prepare), `hotkey.py:72-160` (grammar, formatting), `hotkey.py:269-378` (matching, release, watchdog), `streaming/base.py` (protocol, `CompoundTranscript`), `streaming/websocket_engine.py:25-33,120-255,255-434` (skeleton and three adapters), `streaming/on_device.py:30-130`, `streaming/audio_convert.py`, `config.py`, `pricing.py:8-67`, `overlay.py:11-60` (constants), `paster.py:14-39`, `setup.py` (plist keys and usage strings), `.github/workflows/build.yml` (sign/notarise/release/cask).
- `docs/speed-improvements.md` measured ~470 ms per `startAndReturnError_` and 2–5 s after mic idle; none of its six fixes were applied in the Python code (verified in `recorder.py:121,137`, `controller.py:109-112`, `app.py:101`).
- Installed app signature: identifier `com.ips.mini-whisper`, Team `XPRCQRLN7Y`, designated requirement `identifier "com.ips.mini-whisper" and anchor apple generic … and certificate leaf[subject.OU] = XPRCQRLN7Y` — the requirement a Developer-ID-signed Swift build under the same ID reproduces, so TCC grants (Microphone, Accessibility) match the new binary.
- On-device `SFSpeechRecognizer` (`requiresOnDeviceRecognition = true`) has no one-minute limit; the limit applies to server recognition only. `docs/transcription-engines.md:42` is inaccurate on this point.
- SpeechAnalyzer/SpeechTranscriber (macOS 26): `SpeechTranscriber.isAvailable`, `supportedLocale(equivalentTo:)`, `AssetInventory.assetInstallationRequest(supporting:)` (nil when installed), `SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith:)`, `AVAudioConverter` into that format wrapped as `AnalyzerInput(buffer:)` (the SDK 26.5 Speech interface has no `AnalyzerInputConverter` — corrected by /feature-plan, 2026-09-01), `analyzeSequence`/`finalizeAndFinish(through:)`, `ReportingOption.volatileResults`, `Result.isFinal`.
- GitHub-hosted `macos-26` runners are GA with Xcode 26.6 default; `macos-15` cannot compile SpeechAnalyzer calls.
- Local tooling: Xcode 26.6, Swift 6.3.3, SDK macOS 26.5, xcodegen installed. Homebrew cask `cagriy/tap` `Casks/mini-whisper.rb` points at `cagriy/mini-whisper` releases and `depends_on macos: ">= :ventura"`.
- The user's own config today: `hotkey`, `submit_hotkey`, `cleanup_enabled`, `sound_volume`, `usage` — no `streaming_engine` key, so F32's default rule applies to them.
- Accepted mockups: [Overlay — Breathing](./mockups/mockup-v1-overlay-breathing.html) ([artifact](https://claude.ai/code/artifact/06c3f389-e0ed-49f7-ae69-bc7c8f462ffa)), [Settings — Sidebar](./mockups/mockup-v1-settings-sidebar.html) ([artifact](https://claude.ai/code/artifact/4b8fd1e1-2e90-44f7-8077-826103e7e82e)), [History — List](./mockups/mockup-v1-history-list.html) ([artifact](https://claude.ai/code/artifact/b9d0c016-1b2d-4301-b9c0-60feddf40148)).

## 5. Design

### 5.1 Repository layout and build
```
mini-whisper-swift/
  project.yml                      # xcodegen: app target, local package dep, plist, entitlements, MARKETING_VERSION 0.2.0
  App/                             # app target sources (AppKit shell, SwiftUI windows, layers)
  App/Resources/                   # AppIcon.icns, on.mp3, off.mp3, mini-whisper.png (menu icon), default prompts
  App/Info.plist, App/MiniWhisper.entitlements
  Packages/MiniWhisperCore/        # SwiftPM package, all non-UI logic; `swift test` runs without Xcode project
    Package.swift  Sources/<targets below>  Tests/<one test target per source target>  Tests/Fixtures/
  AppTests/                        # xcodebuild-run tests for app-only pieces (overlay simulation glue, menu)
  scripts/                         # release helpers used by CI (dmg, cask update)
  .github/workflows/build.yml
  features/, README.md, CLAUDE.md, CHANGELOG.md
```
- `xcodegen generate` produces `Mini Whisper.xcodeproj` (git-ignored). `project.yml` sets `PRODUCT_BUNDLE_IDENTIFIER=com.ips.mini-whisper`, `MACOSX_DEPLOYMENT_TARGET=14.0`, `SWIFT_VERSION=6.0`, `SWIFT_STRICT_CONCURRENCY=complete`, `ENABLE_HARDENED_RUNTIME=YES`, `MARKETING_VERSION=0.2.0`, `CURRENT_PROJECT_VERSION=0.2.0`, `LSUIElement=YES`, the four usage strings from `setup.py`, and `CODE_SIGN_ENTITLEMENTS`.
- Package targets (each a separate module, each with its own test target): `MWConfig`, `MWHotkeys`, `MWAudio`, `MWStreaming`, `MWTranscription`, `MWPipeline`, `MWUsage`, `MWHistory`, `MWProfiles`, `MWPaste`, `MWOverlaySim`, `MWSupport` (logging facade, clock/sleep protocols, `AnyError` mapping). Dependencies flow downwards only: `MWPipeline` depends on the others; nothing depends on `MWPipeline`.
- The app target depends on the package and contains only AppKit/SwiftUI code plus platform adapters that implement Core protocols (`KeyEventSource`, `AudioTapSource`, `KeyPoster`, `PasteboardAccess`, `Clock`, `SoundPlayer`).

Why modular: every row above is testable with fakes in `swift test`; the app target holds only what needs AppKit. The one deliberately cohesive unit is `DictationController` — the press/release/generation/fallback rules are a single state machine and splitting them would scatter invariants; it is kept testable by receiving every side effect through protocols (`AudioCapture`, `EngineFactory`, `Transcriber`, `Cleaner`, `Paster`, `SecretStore`, `UsageStore`, `HistoryStore`, `SoundPlayer`, `Clock`).

### 5.3 Data model

**config.json** (superset of the Python schema; unknown keys round-trip):
```json
{
  "hotkey": "shift+cmd_r", "submit_hotkey": "cmd_r",
  "cleanup_enabled": true, "sound_volume": 1.0,
  "streaming_enabled": true, "streaming_engine": "on_device",      // absent → platform default (F32)
  "pricing_overrides": {},
  "usage": {"2026-09-01": {"input_tokens": 0, "output_tokens": 0, "streamed_seconds": {"on_device": 0.0}, "cost_usd": 0.0}},
  "history_retention_days": 7, "idle_stop_seconds": 60, "toggle_max_seconds": 300,
  "speech_model_prompted": false,
  "vocabulary": ["Mini Whisper", "xcodegen"],
  "profiles": [
    {"id": "9f1c…", "name": "Terminal", "bundle_ids": ["com.apple.Terminal", "com.googlecode.iterm2"],
     "cleanup_enabled": false, "submit_key": "enter", "cleanup_prompt": "Keep shell commands verbatim; strip filler words only."}
  ]
}
```
- `submit_key` ∈ `enter | shift_enter | cmd_enter`. `cleanup_prompt` null → `prompt.txt`. Profile `id` is a UUID string. Validation on load: bounds clamped (`history_retention_days` 0–30, `idle_stop_seconds` 10–600, `toggle_max_seconds` 60–1800), unknown `submit_key` → `enter`, duplicate bundle IDs keep the first occurrence.
- Writes are atomic (temp file + `rename`), pretty-printed with 2-space indent and trailing newline like the Python app.

**history.jsonl** — one JSON object per line: `{"id":"uuid","ts":"2026-09-01T17:38:02Z","text":"…","app_name":"Slack","bundle_id":"com.tinyspeck.slackmacgap","engine":"speech_analyzer","streamed_seconds":6.2,"cost_usd":0.001}` (`engine` is `null` and `streamed_seconds` 0 for batch-only dictations). Loaded fully into memory on first access (bounded by retention; thousands of lines at most); rewritten wholesale on delete/prune; appended on new entries. File mode 0600.

**Keychain** — `kSecClassGenericPassword`, `kSecAttrService = "mini-whisper"`, `kSecAttrAccount ∈ {openai-api-key, elevenlabs-api-key, speechmatics-api-key}`, UTF-8 data, login keychain (no `kSecUseDataProtectionKeychain`). The first read of an item created by the Python app can trigger the system “allow access” dialog; “Always Allow” adds this binary to the item ACL; subsequent updates with the same Team ID are covered by the same designated requirement.

### 5.4 Interfaces

**Hotkey events.** `KeyEvent = .keyDown(vk: UInt16, chars: String?) | .keyUp(vk:…) | .flagsChanged(flags: ModifierFlags, vk: UInt16)`; sided modifiers are identified by vk (`cmd_r` 54, `shift_r` 60, `alt_r` 61, `ctrl_r` 62) and canonicalised to `cmd|shift|alt|ctrl` for the held set. Watchdog masks: shift `0x20000`, ctrl `0x40000`, cmd `0x100000`, alt `0x80000`.

**UI events** (`DictationController.uiEvents`, main actor): `.starting`, `.recording`, `.level(rms: Float)` (raw per-buffer RMS; the overlay simulation applies the floor/ceiling and attack/decay), `.caption(text: String, partial: Bool, dimmed: Bool)`, `.captionUnavailable`, `.captionNotice(String)`, `.processing`, `.result(String)`, `.error(String)`, `.idle`, `.usage(today: String, month: String)`.

**Streaming wire protocols** (pinned to the source, 2026-09-01):
- OpenAI: `wss://api.openai.com/v1/realtime`, header `Authorization: Bearer <openai key>`; open `{"type":"session.update","session":{"type":"transcription","audio":{"input":{"format":{"type":"audio/pcm","rate":24000},"transcription":{"model":"gpt-live-transcribe"},"turn_detection":{"type":"server_vad"}}}}}`; chunk `{"type":"input_audio_buffer.append","audio":"<base64 pcm16le@24k>"}`; end `{"type":"input_audio_buffer.commit"}`; events `conversation.item.input_audio_transcription.delta` (accumulate → partial), `…completed` (`transcript` → final, `usage.input_tokens/output_tokens` added, terminal), `error` → fail. Drain 0.2 s.
- ElevenLabs: `wss://api.elevenlabs.io/v1/speech-to-text/realtime?model_id=scribe_v2_realtime&audio_format=pcm_16000`, header `xi-api-key`; no open message; chunk `{"message_type":"input_audio_chunk","audio_base_64":"…","commit":false,"sample_rate":16000}`; end same with `"audio_base_64":"","commit":true`; `partial_transcript`/`final_transcript` → partial, `committed_transcript` → final + terminal, `input_error` → fail. Drain 0.2 s.
- Speechmatics: `wss://eu.rt.speechmatics.com/v2`, header `Authorization: Bearer`; open `{"message":"StartRecognition","audio_format":{"type":"raw","encoding":"pcm_s16le","sample_rate":16000},"transcription_config":{"language":"en","enable_partials":true}}`; chunks are binary frames (seq counter); end `{"message":"EndOfStream","last_seq_no":N}`; `AddPartialTranscript.metadata.transcript` → partial, `AddTranscript.metadata.transcript` → final, `EndOfTranscript` → terminal, `Error` → fail. No drain.

**OpenAI HTTP.** Transcription: `POST /v1/audio/transcriptions` multipart (`file` = `audio.wav`, `model=gpt-4o-mini-transcribe`, `response_format=json`, `instructions` when non-empty), 30 s timeout, response `text` + `usage.input_tokens/output_tokens`. Cleanup: `POST /v1/chat/completions` `{"model":"gpt-4o-mini","temperature":0.3,"messages":[{"role":"system","content":prompt},{"role":"user","content":text}]}`, 15 s timeout, `choices[0].message.content` trimmed, `usage.prompt_tokens/completion_tokens`.

**Settings window** — as [Settings — Sidebar](./mockups/mockup-v1-settings-sidebar.html): 780×560, `NavigationSplitView` with sections General, Hotkeys, Keys, Cleanup, Vocabulary, History, Sound; `Form` with grouped style. General: Live transcript toggle; Engine radio list (SpeechAnalyzer row only on 26+, with `Download model…` button / progress / “Installed”; cloud rows disabled with inline reason until their key exists); “Stop microphone after idle” stepper 10 s–10 min; “Stop tap-to-talk after” stepper 1–30 min. Hotkeys: two capture fields with the source's display strings and behaviour. Keys: three secure fields (masked `sk-…xxxx` for OpenAI, `••••••••••••` for others when set), Save per row, red error line with the source's messages. Cleanup: toggle (disabled + footnote without key), cleanup prompt and transcription instructions editors each with Save Prompt / Open in Editor, profiles table (+/−, detail form: apps chips with Add… listing running apps or an Applications chooser, cleanup toggle, submit key popup, prompt editor; Default row shows “everything else” and uses prompt.txt). Vocabulary: chips + entry field. History: retention slider 0–30 (label “Off” at 0), Open History…, Clear History. Sound: volume slider with preview on release. Every control writes through immediately, as today.

**History window** — as [History — List](./mockups/mockup-v1-history-list.html): 680×480, toolbar search field, day-grouped `List`, row = app glyph (first letters, colour hashed from bundle ID), two-line text, meta line `HH:mm · App · Engine[+ cleanup] · s · $`, actions on hover/selection: `Paste into <App>` (enabled when that app is running), Copy, Delete; footer `Keeping N days · M dictations` and `Clear History…` with confirmation.

### 5.5 Control flow

**Warm press (engine running).** CGEventTap thread → `HotkeyMatcher` → `.pressed(paste)` → main actor `DictationController.hotkeyPressed`: cancel idle-stop timer; emit `.starting` (overlay panel orders front and starts the display link this frame); record `pressAt`; `await audio.beginCapture()` — flag flip; schedule tick at +100 ms; `EngineFactory.make` (config and secrets served from the in-memory cache, §5.9) → `engine.start(sink)` → `audio.attachListener(engine)` (buffers captured before attachment are recorded but not streamed, as in the source). First tap buffer → `AudioEvent.live` → controller emits `.recording`, cancels tick, plays “on”. Each buffer: RMS accumulated, `.level` emitted (coalesced to one per buffer), buffer handed to the engine listener synchronously (SF/SpeechAnalyzer append; websocket engines convert and enqueue).

**Cold press.** Same, but `beginCapture` first awaits `ensureRunning()` (`engine.start()` on a background task, ~0.5 s or more); the tick fires at +100 ms; the breathing ring shows until `.live`.

**Release.** `.released(paste)`: if `now - pressAt < 0.3` → toggle armed, return. Else `stopAndProcess(binding)`: capture frontmost app (bundle ID, name, pid); `recording = await audio.endCapture()`; resolve profile; gate (F11) → discard path; emit `.processing` and dimmed caption; `generation += 1`; spawn processing `Task` with `(recording, engine, sink, profile, target, generation)`; schedule idle-stop at `idle_stop_seconds` from the processing terminus (rescheduled when the job ends).

**Processing job.** `key = secrets.openai`; `result = await engine?.finish(timeout: 5 s)`; choose streamed text per F12; stale? → discard-billing path. If `key == nil`: streamed text → paste raw, else `.error("No API key configured")`. Batch when needed (stale check first); empty → idle path. Cleanup when effective (stale check first). Stale check, bill (F35), `paster.paste(text, into: pid, submit: binding == .pasteSubmit ? profile.submitKey : nil)`, append history (delivered dictations only, F29), “off”, `.result`, `.usage`. Errors → F14 mapping → “off”, `.error`.

**Toggle stop.** Next press while `toggleArmed` → `stopAndProcess`. Cap timer → same path with the “off” sound (the “on” sound is not replayed).

**Idle stop.** Timer → `audio.stop()` → `AudioEvent.stopped`. Sleep notification → immediate stop. Wake → nothing until the next press.

**History paste.** Window records `previousApp` when shown; `Paste` → hide window → `previousApp.activate()` → 150 ms → `paster.paste(text, into: previousApp.pid, submit: nil)`.

**Launch.** `SingleInstanceGuard` → permissions check → onboarding or normal start (create controller, listener, panels, status item; preload sounds; build panels off-screen; no audio engine start) → first-run settings auto-open when no OpenAI key → F32 model dialog when applicable.

### 5.6 Overlay and caption rendering

- Windows: `NSPanel(styleMask: [.borderless, .nonactivatingPanel])`, `level = .floating`, `isOpaque = false`, clear background, no shadow, `ignoresMouseEvents = true`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`, `hidesOnDeactivate = false`. Card 300×300 centred on the target screen; caption 480×180 at `card.minX − 90`, `card.minY − 14 − 180`.
- Drawing: `ConstellationLayer: CALayer` with `draw(in:)` using CoreGraphics from a preallocated `Frame` (fixed-capacity arrays for 24 dots and up to 276 links; no allocation per frame). Driven by `NSView.displayLink(target:selector:)` (macOS 14) at the display's refresh rate; physics steps with `dt = min(elapsed, 0.05)`. Implicit CALayer animations disabled. `contentsScale` follows the screen.
- `ConstellationSimulation` constants: 24 dots, first 10 on ring r=100 with ±0.15 slot angular and ±0.10 radial jitter, remaining 14 uniform in the disc; dot radius 2–5; `k=30`, `c=10`; ambient orbit 10 pt at 1.2 rad/s with per-dot phase; audio displacement `level × 130` along a per-dot angle that random-walks with σ = 2 rad/s × (1 + 40·level); level = attack 0.6 / decay 0.08 one-pole on `clamp((rms − 0.005)/(0.06 − 0.005), 0, 1)`; links for distance < 120 at alpha `(1 − d/120) × 0.6`, width 1; dots white 0.9; background black 0.7, radius 20; label bottom-right 11 pt monospaced digits: `"%.1fs"` while recording, `starting…`, `processing...`.
- Breathing choreography (accepted mockup): `show()` seeds homes, places all dots at the centre with zero velocity, card alpha 0→1 over 120 ms; `starting` homes = ring r = 30 + 6·sin(2πt) around the centre (links drawn); `recording` homes = seeded constellation (the spring carries the expansion); `processing` rotates homes about the centre at 3 rad/s; `result` homes = centre for 260 ms then alpha 1→0 over 120 ms; `error` = horizontal offset `6·sin(60t)·(1 − t/0.45)` px for 0.45 s, then dots hidden and the message drawn centred, 14 pt medium, wrapped with 20 pt margins, 3 s, then hide. With `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`: no spring-from-centre (dots start at homes), no shake, fades only.
- Caption: 7 `CATextLayer`s (14 pt system, line height 22, padding 16/13) plus a cursor layer (`▍`) whose opacity animates with a 0.9 s step keyframe animation while a partial is shown; new last line animates `translateY 8→0` and alpha over 120 ms; older lines 0.45 / current 0.92; dimmed 0.40 / 0.65; wrap by measuring with `NSAttributedString.size()` against 448 pt; `⚠ live transcript unavailable` appended once, dropping the oldest line beyond 7. Redraws only on text change; no per-frame work.
- Placement (F37): `AXUIElementCreateApplication(pid)` → `kAXFocusedWindowAttribute` → position/size → screen containing the centre; else screen containing `NSEvent.mouseLocation`; else `NSScreen.main`; recomputed on every `show()`.

### 5.7 Failure and edge cases
| Situation | Behaviour |
|---|---|
| Engine start fails (no input device, TCC revoked) | `.error("Mic error: <description>")`, no stream, idle-stop timer not scheduled |
| Device/route change while capturing | recording ends, `.error("Audio device changed")`, stream discarded (seconds billed), engine restarted lazily |
| Device change while idle-running | engine marked stopped; next press restarts with new format |
| Sleep | engine stopped immediately; capture in progress ends as above |
| Websocket never opens | after 60 s of buffered audio → engine fails → caption unavailable → batch |
| Provider error / unknown message | adapter throws → single-shot fail → batch |
| `finish` timeout 5 s | stream unusable, partial discarded, batch |
| SF recognizer unavailable (locale) | engine fails at start → batch |
| SpeechAnalyzer assets missing / locale unsupported / installing | SFSpeechEngine used silently |
| Cloud key removed out-of-band | on-device default + one caption notice per run |
| Two presses within processing | generation guard; stale job stops before the next network call; seconds billed only |
| Toggle armed and app quits | `abort()` finishes the engine with 0.5 s timeout, bills seconds, stops audio |
| Paste into an app that quit between release and paste | `CGEventPostToPid` to a dead pid is a no-op; if `NSRunningApplication(pid)` is nil → `.error("Target app is no longer running")`, clipboard restored |
| Accessibility revoked | pre-paste check → `.error(...)`; hotkeys stop working — `GlobalKeyListener` detects `CGEventTapIsEnabled == false` on its 100 ms watchdog and re-enables or, when AX is gone, logs and shows the error once |
| Pasteboard changed by the user during the 300 ms window | snapshot not restored |
| Corrupt config | backup + defaults, warning logged |
| History file corrupt line | skipped and logged; rewritten clean on next prune |
| Retention set to 0 | file deleted, writes disabled, menu `Last:` still works (in-memory) |
| Second instance | activates the first and exits before creating any window |
| Onboarding Continue | in-process start; no relaunch |

### 5.8 Security
- Secrets only in the Keychain; secure text fields never echo stored values; logs redact keys (never logged) and never include transcript text or prompts above DEBUG.
- Network: TLS to the three vendors only; an ephemeral `URLSession` configuration (no cookie or cache persistence); no telemetry.
- Prompt content is user-controlled by design; vocabulary and profile prompts are appended verbatim — same trust model as `prompt.txt` today.
- Synthetic key events go only to the resolved pid; the app never posts to the session tap. Accessibility trust is checked before posting.
- History file 0600 under the user's home; retention 0 leaves no file. README's privacy section is updated to state what is stored locally.
- Hardened runtime, no sandbox (Accessibility and `CGEventPostToPid` require it), no `com.apple.security.automation` entitlement (not needed since 0.1.7's `CGEventPostToPid`).

### 5.9 Performance
- Press path: event tap → main actor hop → panel `orderFront` + display link: one frame. Capture flag flip: microseconds. First buffer: 1024 frames ≈ 21 ms at 48 kHz (source: 85 ms). Cold engine start: unchanged CoreAudio cost, now paid at most once per idle period.
- Config and secrets are cached in memory (`ConfigStore` observes file changes via `DispatchSource`; `KeychainStore` caches each account after its first read and invalidates on save/remove from Settings), removing the per-press file/Keychain reads the Python app performs.
- Overlay: 276 distance checks + ≤276 CG strokes per frame in a preallocated buffer; expected < 1 ms per frame. Caption redraws only on change.
- Network work runs on `URLSession` tasks; nothing blocks the main actor.

### 5.12 Testing strategy
Swift Testing in `Packages/MiniWhisperCore/Tests`, one suite per component, no hardware/network/TCC:
- `HotkeyComboTests`: parse/format/build table incl. the source defaults and error cases. `HotkeyMatcherTests`: exact vs superset matching, `shift+cmd_r` vs `cmd_r` non-collision, release on modifier-up, safety net, watchdog release for modifier-trigger bindings, capture mode incl. modifier-only capture and rejection.
- `PCMConverterTests`: chunked output equals whole-buffer output for random chunk splits and 44.1k/48k→16k/24k. `WAVEncoderTests`: header fields, sample count.
- `TranscriptAssemblerTests`: port of the Python restart-heuristic cases. `WebSocketEngineTests`: fixture-driven `FakeWebSocketConnection` replaying `Tests/Fixtures/streaming/{openai_realtime,elevenlabs,speechmatics}.json` (copied from the Python repo, same schema: `await_client` / `server` steps), asserting partial/final sequences, token usage, end-of-audio gate, drain, 60 s pre-connect failure, finish timeout. `EngineFactoryTests`: every rule in F23 with fake platform/secrets.
- `DictationControllerTests` with fakes for audio, engines, transcriber, cleaner, paster, secrets, usage, history, sounds and a virtual clock: hold vs toggle, cap, gate, tick/tock timing (tick only when live > 100 ms), generation staleness at each checkpoint and its billing, no-key rule, streamed-vs-batch selection, error mapping, idle-stop scheduling, device change during capture, profile/submit-key routing, history append only on delivery.
- `PricingTests`/`UsageStoreTests`: cost maths incl. overrides, row formatting, month prune, migration. `ConfigStoreTests`: defaults, corrupt backup, unknown-key round-trip, clamping, atomic write. `HistoryStoreTests`: append/prune/retention 0/search/corrupt line. `ProfileResolverTests`, `PromptComposerTests`. `PasterTests`: key sequences per submit key via `FakeKeyPoster`, restore-only-if-unchanged. `ConstellationSimulationTests`: seeding counts/radii, convergence to homes, breathing ring radius bounds, rotation, no NaNs at dt clamp.
- App target (`xcodebuild test`): `ConstellationLayer` renders 600 consecutive frames from a scripted simulation without error (smoke test; allocation is checked once with Instruments' Allocations template and the result recorded in the plan's acceptance notes), menu item order, Settings gating view-model.
- Integration (opt-in, `MW_INTEGRATION=1`, real OpenAI key from env): transcribe + clean the three WAV fixtures copied from the Python repo; mirrors the source CI gating.

## 6. Alternatives considered
- Overlay “Quiet” (fades only) and “Glass” (system material card) — mockups offered and rejected by the user in favour of “Breathing”; Glass also risked contrast on light desktops and a divergent look below macOS 26.
- Settings “Toolbar tabs” — rejected for narrower panes; the profiles table and two editors need the width.
- History “Table” — rejected: dictations are prose; the list shows full sentences without a detail pane.
- Per-press engine start/stop (true parity) and a permanently running engine — rejected in the storm; idle-stop with a configurable timeout chosen.
- New bundle identity with import — rejected in the storm; drop-in keeps TCC and Keychain continuity.
- Metal (`MTKView`) for the overlay — rejected: 24 dots and ≤276 lines are trivial for CoreGraphics in a preallocated layer; Metal adds a shader pipeline for no measurable gain.
- 24 `CAShapeLayer`s for dots plus one path for links — rejected: per-link alpha needs per-link layers or a custom draw anyway; a single custom layer is simpler and allocation-free.
- `NSEvent.addGlobalMonitorForEvents` instead of `CGEventTap` — rejected: it cannot observe events reliably for modifier-only triggers in all apps and offers no tap-disabled signal for the watchdog.
- SwiftPM-only build with a bundling script — rejected: Xcode debugging of app lifecycle and TCC behaviour is needed; xcodegen keeps the project reviewable.
- `MenuBarExtra`-only app — rejected: panel levels, mouse transparency and per-frame drawing need AppKit.
- SQLite for history — rejected: a few thousand lines at most; JSONL keeps the cask's `zap` accurate and needs no schema migration.
- Sending audio to SFSpeechRecognizer at 16 kHz after conversion — rejected: the source appends hardware-rate buffers and the recogniser accepts them; conversion would add latency for nothing.
