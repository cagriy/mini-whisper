Mockup — not shipping code · Feature v4 · “Meetings List” · Accepted 2026-11-09

The Meetings window: every recorded meeting, newest first, grouped by day, in the accepted History list's shape (680×480, search in the title bar, two-line rows, hover actions, footer). Shown in three states top to bottom: the populated list with the Export menu open, a search across titles, transcripts, notes and summaries, and the empty state before the first meeting. What to judge: what a row shows (title, summary excerpt, meta line), how search hits are presented, and where Start Meeting sits. Design language: the accepted v1 History list mockup — Messages/Notes-style list, light appearance, 13 pt system type, 30 px glyph per row.

State 1 · The list

One row per meeting: title (default is “<app> · <date time>” until renamed), the first sentence of the summary or, when there is none, the first transcript line in italics, then a meta line with start time, duration, mode, speaker count, cost and what is on disk. Hover shows Open, Export and Delete; the Export menu offers transcript, summary, both, and Delete audio.

State 2 · Searching

Search matches titles, transcript text, notes and summaries as you type. A matching row keeps its title and meta line and swaps the excerpt for up to two hit snippets, each labelled with where it was found and, for transcript and note hits, the meeting time. Opening a hit opens the meeting scrolled to that segment.
