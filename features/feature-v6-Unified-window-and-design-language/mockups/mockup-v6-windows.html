What this proposes

  1. Small windows stay small windows. Standard title bar, fixed size, not resizable. Inside: the same surfaces, type, fields, switches and pill buttons as the main window, following the same Theme setting.
  2. Correction. Today's fields in today's order. Field labels move from small capitals to sentence case, Scope becomes a pill switch, and Save is the one filled button. The saved state keeps its tick, message and Done.
  3. Onboarding. A serif title, the explanation, then the two permissions as one card: each shows its state and an Open Settings button until granted. Continue wakes when both are granted. It still cannot be closed before that.
  4. About. A small window instead of an alert: the cloud-and-pulse mark on the accent blue, the name in the display serif, the version and today's three lines of text. It closes with the red button; there is no OK.
